# Why Do We Pray?

A tap-to-flip card activity for Middle School. Each card shows a symbol and a faint clue word on the front; tap (or click on a smartboard) to flip it and reveal the reason.

Live: https://techrabbi.org/why-pray/

Single self-contained `index.html` — no build step, no dependencies. Jewel-tone deck, 3×3 grid.
